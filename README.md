# Music-Player

A simple **web-based music player** built with HTML, CSS, and JavaScript.  
Users can view a playlist, play/pause songs, navigate tracks, and delete songs from the playlist.  

---

## Features

- Play, pause, skip next/previous, and shuffle tracks  
- View song title, artist, duration, and album art
- Delete songs from the playlist  

---

## Tech Stack

- **HTML** – structure and layout  
- **CSS** – styling, responsive design  
- **JavaScript** – playlist management, audio controls, and interactivity  

---

## How to Use

1. Open `index.html` in your browser  
2. Click a song in the playlist to play it  
3. Use the play/pause, next, previous, or shuffle buttons to control playback  
4. Optionally, delete songs using the “X” button
