# Music-Player


A **static music player prototype** demonstrating **front-end interactivity and media handling**. Built with **HTML, CSS, and JavaScript**, this project allows users to play local audio files from a playlist with interactive controls.

---

## Portfolio Pitch

This project showcases the ability to create a responsive, interactive front-end application that handles media playback entirely on the client side. It demonstrates DOM manipulation, event handling, and dynamic UI updates, making it an excellent example of a hands-on front-end coding project.

---

## Features

- Play, pause, skip next/previous, and shuffle tracks.
- Dynamic playlist rendering with clickable song items.
- Delete tracks from the playlist.
- Display current track title, artist, and album art.
- Responsive design optimized for mobile and desktop.
- Visually highlights the currently playing track.

---

## Limitations

- Does **not connect to any server** or streaming service; it only plays **local audio files** included in the project.
- Playlist changes (like deleting tracks) are **not persisted** on page reload.
- No user accounts or track search functionality.

---

## Potential Upgrades

- Add **progress bar and seek functionality**.
- Implement **localStorage** to persist playlist and track progress.
- Integrate a **server or API** for dynamic track streaming.
- Enable **drag-and-drop playlist reordering**.
- Add **theme switching** (dark/light mode) for better UI customization.

---

## Technologies Used

- HTML5
- CSS3 (Responsive design)
- JavaScript (DOM manipulation and Audio API)
